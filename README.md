## ✨ Features

* 🔍 **Workshop browsing & filtering** — search and explore available workshops
* 📋 **Workshop detail pages** — view instructor, topics, and key information
* 📝 **Booking form with validation** — structured form with input validation
* ✅ **Booking confirmation flow** — user receives confirmation after submission
* 📱 **Fully responsive design** — optimized for mobile, tablet, and desktop
* ⚡ **Fast performance** — built using Vite for efficient loading

## 🚀 Getting Started

```bash
git clone https://github.com/tanmay-alpha/fossee-workshop-booking
cd fossee-workshop-booking
npm install
npm run dev
```

Open `http://localhost:5173`
